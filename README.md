## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/hema470/Skylark-Monday-BI-Agentt.git
```

Move into the project

```bash
cd Skylark-Monday-BI-Agentt
```

Run using Docker

```bash
docker build -t skylark-bi .
docker run -p 8000:8000 skylark-bi
```
